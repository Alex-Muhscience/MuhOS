    MuhOS is a pre-release. It's ready for testing and daily use by people who are comfortable reporting problems. It has been tested in Fedora virtual machines but not yet on a wide range of hardware.

    Before you start

    SystemFedora 44 Workstation, x86_64
    Login screenGDM (Fedora's default). MuhOS adds itself as a choice; GNOME stays available.
    CompositorHyprland 0.56, from the lionheartp/Hyprland COPR (step 2)
    GraphicsAny GPU that Hyprland supports

    Install

    1. Download the packages

      From the latest release, download every .noarch.rpm and .x86_64.rpm file, plus SHA256SUMS, into one folder. You don't need the .src.rpm files unless you want to build from source.

    2. Open a terminal in that folder and install

      cd ~/Downloads
sha256sum --check --ignore-missing SHA256SUMS   # every file should say OK
sudo dnf copr enable lionheartp/Hyprland
sudo dnf install ./muhos-*.noarch.rpm ./quickshell-*.x86_64.rpm ./matugen-*.x86_64.rpm ./whitesur-*.noarch.rpm

      dnf will note that the packages aren't signed yet; the checksums are how you verify them for now.

    3. Log in to MuhOS

      Log out. On the login screen, click your name, then the gear button at the bottom right, choose MuhOS (Hyprland), and sign in. The first start shows a short welcome.

    Updating

    Download the new release and run the same sudo dnf install command. Your settings are kept.

    Uninstalling

    sudo dnf remove muhos whitesur-gtk-theme whitesur-icon-theme
rm -r ~/.config/muhos ~/.config/dconf/muhos                # optional: MuhOS settings
rm -r ~/.config/serpantinum ~/.local/state/serpantinum     # optional: shell settings

    MuhOS never changes your GNOME setup or other configuration, so nothing else needs restoring.

    Build it yourself

    Every release includes source RPMs, and the whole build is in the repository. See Build it yourself in the README.
