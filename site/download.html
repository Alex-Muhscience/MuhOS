Files in this release

    MuhOS 0.1.0 is the first release. It's tested in Fedora 44 and 45 virtual machines and in daily use on a laptop with Intel and NVIDIA graphics. On other hardware, please report problems or tell us how it runs with a hardware report.

    Before you start

    SystemFedora 44 or 45 Workstation, x86_64
    Login screenGDM (Fedora's default). MuhOS adds itself as a choice; GNOME stays available.
    CompositorHyprland 0.56 or newer (tested with 0.57.2), from the lionheartp/Hyprland COPR (step 2)
    GraphicsAny GPU that Hyprland supports

    Install with one command

    Open a terminal and run:

    curl -fsSL https://alex-muhscience.github.io/MuhOS/install.sh | bash

    It lists the files with their sizes and the total download, shows a progress bar for each, and at the end asks how MuhOS should update.

    The installer checks that you're on Fedora 44 or 45, downloads the newest release's packages for your version from GitHub, checks every package against the release's SHA256SUMS (it stops if anything doesn't match), enables the Hyprland COPR and installs with dnf. It asks before changing anything, and dnf shows you the full list first. The packages aren't signed yet, so dnf mentions that it skipped signature checks.

    Then log out, click your name on the login screen, choose MuhOS (Hyprland) with the gear button at the bottom right, and sign in.

    Prefer to read the installer first?

    It's a short script; download it, look through it, then run it:

    curl -fsSLO https://alex-muhscience.github.io/MuhOS/install.sh
less install.sh
bash install.sh

    Options: --dry-run downloads and checks without installing, --keep DIR keeps the packages, --tag v0.1.0 picks a release, and --yes doesn't ask. With the one-liner, pass them as | bash -s -- --dry-run. Source: site/install.sh.

    Install by hand instead

    From the latest release, download every .noarch.rpm and .x86_64.rpm file plus SHA256SUMS into one folder (the .src.rpm files are only for building from source). Then, in that folder:

    sha256sum --check --ignore-missing SHA256SUMS   # every file should say OK
sudo dnf copr enable lionheartp/Hyprland
sudo dnf install ./muhos-*.noarch.rpm ./quickshell-*.x86_64.rpm ./matugen-*.x86_64.rpm ./whitesur-*.noarch.rpm

    Updating

    Once MuhOS is installed, update it with:

    muhos-update

    It shows what's new and the download size, downloads with progress bars, verifies the packages and asks before installing. Settings' Update button runs it for you, and your settings are kept. Coming from a pre-release older than pre.8, run the install command once more instead.

    Choose how MuhOS updates (the installer asks once; change it any time):

    muhos-update --mode manualDefault. Nothing in the background; update when you want.
    muhos-update --mode notifyChecks once a day; a notification offers to update.
    muhos-update --mode autoInstalls new releases once a day in the background, then tells you to log out and back in.

    Uninstalling

    sudo dnf remove muhos whitesur-gtk-theme whitesur-icon-theme
rm -r ~/.config/muhos ~/.config/dconf/muhos                # optional: MuhOS settings
rm -r ~/.config/serpantinum ~/.local/state/serpantinum     # optional: shell settings

    MuhOS never changes your GNOME setup or other configuration, so nothing else needs restoring.
