Useful settings

Most things are in the Settings app. A few live in ~/.config/serpantinum/settings.json:

SettingEffect
"bar": { "layout": "hybrid" }The earlier GNOME-style menu bar, with workspace dots and a clock island.
"bar": { "design": "classic" }Serpantinum's original design everywhere.
"muhos": { "solidPanels": true }Solid panels instead of glass, like "Reduce transparency" on a Mac.
"general": { "ipGeolocation": true }Look up your location from your IP address (off by default).

Troubleshooting

"MuhOS (Hyprland)" isn't on the login screen

Check that Hyprland installed: it comes from the COPR enabled in the install steps. Run rpm -q hyprland muhos.

Apps look like GNOME in dark mode

That's expected for now. WhiteSur's dark theme doesn't render GNOME 50 apps correctly, so in dark mode apps use GNOME's own dark style. If you switch Dark Style while apps use WhiteSur, they change at your next login.

Firefox doesn't look like the other apps

Firefox draws its own interface, so GTK themes don't style it.

Something looks wrong or the shell crashed

These commands show what happened. Please include their output when you report a bug:

journalctl --user -u muhos-shell -b             # shell logs
systemctl --user status muhos-session.target    # is the session running?
Hyprland --verify-config -c ~/.config/muhos/hypr/hyprland.lua
muhos reload                                     # restart the shell's interface
Does MuhOS change my GNOME session?

No. MuhOS keeps its own app settings (theme, icons, font, window buttons) in a separate profile that's only used in the MuhOS session, and clears it when you log out.
