# VM benchmark: 0.1.0-0.1 vs 0.1.0-0.8 (2026-10-18/19)

## Setup

| | |
|---|---|
| Builds | baseline `muhos-0.1.0-0.1` (upstream shell, packaging only); `muhos-0.1.0-0.8` (main `3dc7546`) |
| Packages | quickshell 0.3.2-1.muhos1, matugen 4.2.0-1.muhos1, hyprland 0.56.2-3 (COPR lionheartp/Hyprland) |
| Guest | Fedora 44 Cloud Base, 4 vCPU (KVM, host CPU), 6 GiB RAM, virtio-vga 1920x1080, software rendering, no audio device |
| Host | Intel TigerLake-H laptop, Fedora 44 |
| Method | `tests/vm/bench <dir> <scenario> 5 60 60`: 5 runs per scenario, each on a fresh overlay of the same installed disk, 60 s warm-up, then CPU over 60 s from /proc/PID/stat and memory from /proc/PID/smaps_rollup. Median and [min-max] reported. |
| Scenarios | `welcome`: first login, welcome screen shown and left alone. `desktop`: first-launch flag set, idle desktop. |

## Results

| Scenario | Metric | 0.1 baseline | 0.8 | Change |
|---|---|---:|---:|---|
| welcome | quickshell CPU (one core) | 130.12% [129.43-130.92] | 0.53% [0.52-0.58] | about 245x lower |
| welcome | quickshell PSS | 657.1 MiB [653.7-669.2] | 566.4 MiB [563.6-566.9] | -91 MiB |
| welcome | startup | 2.16 s [2.13-2.63] | 2.79 s [2.37-3.17] | slower, ranges overlap |
| desktop | quickshell CPU (one core) | 0.62% [0.55-0.63] | 0.52% [0.50-0.57] | ranges overlap: no claim |
| desktop | quickshell PSS | 487.0 MiB [486.4-496.3] | 503.2 MiB [496.6-505.8] | **+16 MiB (regression)** |
| desktop | Hyprland PSS | 174.6 MiB [174.1-178.2] | 173.2 MiB [172.5-177.0] | no change |
| desktop | startup | 2.37 s [2.34-2.39] | 2.33 s [2.21-4.49] | no change |

Intermediate builds, same method:

| Build | desktop PSS | welcome CPU |
|---|---:|---:|
| 0.2 | 488.7 MiB | 130.93% |
| 0.3 | 490.1 MiB | 130.20% |

## Findings

- The rebuilt welcome screen (0.5) removes the cost of the old one: it idles
  instead of animating full-screen while waiting for input, and uses 91 MiB
  less memory.
- Idle desktop memory grew by 16 MiB between 0.3 and 0.8; the ranges do not
  overlap. Builds 0.4-0.8 added a default wallpaper (now actually loaded),
  the Adwaita Sans font, the Papirus icon theme and native text rendering.
  The cause has not been isolated; until it is, this is an open regression.
- Desktop CPU differences are within run-to-run noise.
