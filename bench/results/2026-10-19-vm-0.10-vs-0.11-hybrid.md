# VM benchmark: Hybrid bar (0.1.0-0.11) vs 0.1.0-0.10 (2026-10-19)

Same setup and method as `2026-10-19-vm-0.1-vs-0.8.md` (headless Fedora 44
VM, software rendering, `tests/vm/bench <dir> desktop 5 60 60`, medians with
[min-max]). Only the idle desktop scenario was run.

0.11 (main `fe0b25d`) differs from 0.10 by: the Hybrid menu bar (transparent,
with a clock island; its layer surface is taller, 34 + 92 px, so the island
can expand), the control centre (created on first use, so not running in this
idle test), Adwaita icons instead of Fluent, and per-surface blur rules
(`muhos-bar` with ignore_alpha 0.3, `muhos-panel`/`muhos-welcome` with 0.1).

## Results (idle desktop)

| Metric | 0.1 baseline | 0.10 | 0.11 | 0.10 -> 0.11 |
|---|---:|---:|---:|---|
| quickshell CPU (one core) | 0.62% | 0.07% [0.05-0.07] | 0.07% [0.07-0.07] | no change |
| quickshell PSS | 487.0 MiB | 473.0 MiB [471.4-479.5] | 470.7 MiB [469.5-474.8] | ranges overlap: no claim |
| quickshell RSS | 558.4 MiB | 548.0 MiB | 543.6 MiB | ranges overlap: no claim |
| Hyprland PSS | 174.6 MiB | 185.0 MiB [180.9-185.2] | 203.1 MiB [202.6-207.6] | **+18 MiB; ranges do not overlap** |
| startup | 2.37 s | 2.10 s | 2.41 s [2.28-2.54] | ranges overlap: no claim |

## Findings

- The shell itself is unchanged from 0.10: still about 9x less idle CPU than
  the 0.1 baseline and slightly less memory.
- Hyprland's memory grew again, to 28.5 MiB above the baseline. The most
  likely cause is blur on a larger layer surface (the bar now spans the full
  width and is 126 px tall, against a 48 px band before). Not yet isolated.
