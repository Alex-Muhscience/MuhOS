# VM benchmark: new MuhOS bar (0.1.0-0.10) vs 0.1.0-0.8 (2026-10-19)

Same setup and method as `2026-10-19-vm-0.1-vs-0.8.md` (headless Fedora 44
VM, software rendering, `tests/vm/bench <dir> desktop 5 60 60`, medians with
[min-max]). Only the idle desktop scenario was run.

0.10 (main `e23cae2`) differs from 0.8 by: the new MuhOS bar replacing
upstream's, Fluent app icons instead of Papirus, the Material Symbols font,
and the Hyprland blur rule for `muhos-*` surfaces.

## Results (idle desktop)

| Metric | 0.1 baseline | 0.8 | 0.10 | 0.8 -> 0.10 |
|---|---:|---:|---:|---|
| quickshell CPU (one core) | 0.62% [0.55-0.63] | 0.52% [0.50-0.57] | 0.07% [0.05-0.07] | lower; ranges do not overlap |
| quickshell PSS | 487.0 MiB [486.4-496.3] | 503.2 MiB [496.6-505.8] | 473.0 MiB [471.4-479.5] | -30 MiB; ranges do not overlap |
| quickshell RSS | 558.4 MiB | 575.1 MiB | 548.0 MiB | -27 MiB |
| Hyprland PSS | 174.6 MiB [174.1-178.2] | 173.2 MiB [172.5-177.0] | 185.0 MiB [180.9-185.2] | **+12 MiB** |
| startup | 2.37 s | 2.33 s | 2.10 s [2.07-2.38] | ranges overlap: no claim |

## Findings

- Quickshell's idle CPU dropped about sevenfold and its memory fell below the
  0.1 baseline, which also cancels the 0.8 memory regression. Part of the CPU
  difference is behavioural: upstream's bar showed seconds and redrew every
  second, the MuhOS bar shows minutes. The four changes were measured
  together, so this run does not split the gain between them.
- Hyprland uses 12 MiB more. The likely cause is the new blur rule (blur
  needs extra framebuffers), but it has not been isolated.
